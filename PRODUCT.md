# Product

## Register

product

## Platform

web

## Users

Software engineers, AI agent builders, and power developers running Windows 11 (Build 22000+) who connect local coding agents such as Claude Code and Cursor to host-level capabilities. They work at high desktop DPI in multi-hour coding sessions alongside dark IDEs and terminals, expecting instant scannability, keyboard-first ergonomics, and zero ambiguity when inspecting ports, toolchains, or approving privileged local operations.

## Product Purpose

KeelDesk provides a single-instance Windows 11 system-tray MCP (Model Context Protocol) runtime spine paired with a local developer environment workbench. It exposes trusted host inspection and port governance tools over loopback Streamable HTTP while gating destructive actions behind real-time human-in-the-loop desktop confirmation. Success means background invisibility during routine Safe queries and immediate, unmistakable clarity when an external agent requests a privileged operation.

## Positioning

The native Windows 11 MCP runtime and developer workbench built with IDE-grade monochrome precision and human-in-the-loop safety.

## Brand Personality

Graphite, surgical, geek-minimalist. Benchmarked against Cursor and Vercel: stark near-black tonal surfaces, razor-sharp 1px hairlines, monospace-fluent technical telemetry, and extreme chromatic restraint where color speaks exclusively to active focus or live runtime state.

## Anti-references

- Never use gradient text (`background-clip: text`), neon AI glows, or decorative glassmorphism across workbench panels.
- Never use colored side-stripe borders (`border-left` or `border-right` > 1px) on alerts, rows, or cards.
- Never use spacious SaaS marketing hero cards, bubbly candy-pill (`rounded-full`) text badges, or playful bounce animations.
- Never introduce browser-style full-page scrollbars, custom HTML fake window caption buttons, or uncalibrated light-mode surfaces that clash with the Win32 DWM `#111116` dark titlebar.
- Never scatter ad-hoc font sizes (`text-[10px]`, `text-[11px]`, `clamp()`), arbitrary spacing magic numbers, or non-concentric nested border radii.

## Design Principles

1. Disappear into the workflow until human judgment is required.
2. Enforce unified structural scales for typography, spacing, and concentric corner radii across every primitive and panel.
3. Separate surfaces with subtle graphite tonal steps and 1px hairlines rather than drop shadows.
4. Reserve chromatic saturation strictly for the single Keel Indigo focus accent and live semantic telemetry states.
5. Maintain pixel-locked vertical alignment from panel header to table gutter to footer status strip.

## Accessibility & Inclusion

Targets WCAG 2.2 AA contrast (minimum 4.5:1 for all body, caption, and placeholder copy; minimum 3.5:1 for scrollbar thumbs and interactive boundaries) across the dark-only surface ramp. Supports full keyboard navigation with focus-visible rings, accessible Radix tooltips in place of native HTML `title` attributes, `aria-live="polite"` state announcements, `prefers-reduced-motion` instant transitions, and Windows 11 High Contrast (`forced-colors: active`) border and indicator fallbacks.
