# `tauri-plugin-keeldesk`

Standard Tauri v2 plugin (`plugin:keeldesk`) wrapping [`keeldesk-core`](../keeldesk-core/README.md) with namespaced `tauri-specta` commands, typed telemetry events, capability permissions, main-window tray wakeup, and graceful exit shutdown.

Part of the [**KeelDesk**](../../README.md) workspace monorepo.

## Features

- **Plugin Lifecycle & Tray Wakeup**: Starts `KeelRuntime` inside Tauri's async runtime, automatically unminimizes and focuses the configured desktop window when a `ConfirmRequired` tool requests human approval, and calls `runtime.shutdown()` on `tauri::RunEvent::Exit`.
- **Typed `tauri-specta` Contract**: Exports 16 namespaced `plugin:keeldesk|*` commands and 5 `plugin:keeldesk:*` events directly to [`packages/react/src/bindings.ts`](../../packages/react/src/bindings.ts).
- **Tauri v2 ACL Permissions**: Ships `permissions/default.toml` (`"keeldesk:default"`) alongside autogenerated per-command permission schemas via `tauri-plugin`.

## Rust Registration

```rust
use keeldesk_core::{KeelConfig, KeelToolRegistry};

let config = KeelConfig::from_env();
let mut registry = KeelToolRegistry::new();
// Attach application-specific Safe / ConfirmRequired tools to `registry`...

tauri::Builder::default()
    .plugin(
        tauri_plugin_keeldesk::Builder::new()
            .config(config)
            .tool_registry(registry)
            .build(),
    );
```

Enable `"keeldesk:default"` in your app's `capabilities/default.json`:

```json
{
  "permissions": ["core:default", "keeldesk:default"]
}
```

## Architectural Boundary

`tauri-plugin-keeldesk` depends only on `keeldesk-core`, `tauri`, and `specta`/`tauri-specta`. It must **never** import `apps/env-workbench` business modules.
